# FM24-26 Kit Converter

A small desktop tool that converts Football Manager 2024 3D kit textures to
a form that is compatible with Football Manager 26.

All of the groundwork for this was performed by roundel0 on the Sortitoutsi forums on the thread:
[Transferring 3D outfits from FM24 to FM26 in Photoshop](https://sortitoutsi.net/content/74713/transferring-3d-outfits-from-fm24-to-fm26-in-photoshop?page=3#comment_854826).

## Installation
The converter is distributed as a single `.exe` file. To install it, simply download the latest release from the [releases page](https://github.com/jacksanders02/fm-24-26-kit-converter/releases/)
(find the latest release, scroll down to "Assets", and click on `fm24-26-kit-converter-x.y.z.exe`), and then run the downloaded executable.
